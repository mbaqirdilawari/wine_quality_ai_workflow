  Key decisions:
  - Structure: a small wine_analysis/ package with one job per module: config,
    data (load, inspect, clean), explore, model, plots, and main. Only main.py
    prints and reads settings; the other modules just return results, so they're
    easy to test. It's deliberately simple: no src/ folder, and everything runs
    from the repo root with python -m.
  - Clean first: duplicates are removed straight after loading, before anything
    else. If they weren't, identical wines could end up in both the training and
    test sets and make the scores look better than they are. Outliers stay
    because they are real wines, and the plan requires that reason to be printed
    and written in the README.
  - Model: a linear regression with an 80/20 split and a fixed random seed (42).
    It reports R² and RMSE for the 3-feature set and the 11-feature set; type
    is left out. The plan says to expect an R² of about 0.2–0.3 and to report
    that honestly, so the tests don't require high accuracy.
  - Paths: set with WINE_DATA_PATH and WINE_OUTPUT_DIR, defaulting to
    data/wine_quality_merged.csv and outputs/.
  - Container: built on python:3.12-slim. It runs the analysis by default, and
    make docker-test runs the tests in the same image. The data is copied into
    the image so a plain docker run works. Charts get out because make
    docker-run connects your local outputs/ folder to the container's output
    folder.
  - Docker Compose: not needed. It's a single container with no other services
    to connect.
  - Tests: unit tests on small made-up data (including empty data, missing files
    and columns, outliers kept, and that cleaning doesn't change its input),
    regression tests against the real CSV's counts, and one end-to-end test that
    runs main() with temporary folders.

    - Your project path contains spaces, so every path in the Makefile,
      especially the Docker folder links, must be quoted.
    - Docker Desktop needs permission to access the OneDrive folder.
    - Quality 9 has only 5 wines.

  - The charts use matplotlib only, without seaborn.

Downsides of adding Compose (all minor):

    environment variables now live in both the Makefile and docker-compose.yml,
